# Household Demographics and Product Sales Analysis

## Project Overview

This project analyzes household transaction data by combining retail purchase information, household demographic details, and product department data. Using Python and Pandas, the project performs data loading, data type optimization, data aggregation, table merging, and pivot table analysis to explore purchasing behavior across different household age groups and product departments.

The analysis focuses on understanding household sales performance and identifying which product departments generate the highest sales among different demographic groups, particularly the youngest demographic.

## Key Features

- Loading transaction data using Pandas
- Selecting specific columns from large datasets to optimize memory usage
- Converting columns into appropriate integer data types
- Converting demographic columns into categorical data types
- Grouping transactions by household
- Calculating total sales value for each household
- Merging transaction data with household demographic information
- Performing inner joins to retain matching records
- Loading product information and selecting relevant columns
- Combining product, transaction, and demographic datasets
- Creating pivot tables based on household age groups and product departments
- Calculating total sales value across demographic and department combinations
- Exporting the final pivot table to an Excel file

## Dataset Overview

The project uses three CSV datasets:

### 1. project_transactions.csv

Contains household transaction and purchase information.

| Column | Description |
|---|---|
| household_key | Unique household identifier |
| BASKET_ID | Unique transaction basket identifier |
| DAY | Day of the transaction |
| PRODUCT_ID | Unique product identifier |
| QUANTITY | Number of units purchased |
| SALES_VALUE | Total sales value of the transaction |

### 2. hh_demographic.csv

Contains household demographic information.

| Column | Description |
|---|---|
| AGE_DESC | Household age-group description |
| INCOME_DESC | Household income category |
| household_key | Unique household identifier |
| HH_COMP_DESC | Household composition description |

### 3. product.csv

Contains product-related information.

| Column | Description |
|---|---|
| PRODUCT_ID | Unique product identifier |
| DEPARTMENT | Product department |

## Data Processing and Analysis

### Data Type Optimization

The project converts selected transaction columns into more memory-efficient data types:

- DAY – int32
- QUANTITY – int32
- PRODUCT_ID – int32

Demographic columns are converted into categorical data types to improve memory efficiency and support demographic analysis.

### Household Sales Aggregation

The transaction dataset is grouped by `household_key` to calculate the total sales value generated by each household.

The resulting aggregated dataset provides a household-level view of purchasing activity.

### Data Integration

The project combines three datasets using Pandas merge operations:

1. Transaction data is merged with household demographic data using an inner join.
2. Product information is merged with transaction data using an inner join.
3. The resulting product-transaction dataset is merged with household demographics using an inner join.

Inner joins ensure that only records with matching information across the datasets are retained.

## Demographic and Product Department Analysis

The final analysis creates a pivot table using:

- **Index:** AGE_DESC
- **Columns:** DEPARTMENT
- **Values:** SALES_VALUE
- **Aggregation:** Sum

This pivot table summarizes total sales value across different household age groups and product departments.

The analysis is intended to identify which product department performs best among the youngest demographic group.

## Output File

The project exports the final pivot table into an Excel workbook.

- **File Name:** pivot_table.xlsx
- **Sheet Name:** My_data

The Excel output provides a structured summary of sales performance across household age groups and product departments.
